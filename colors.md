# 🎨 Guía de Estilos: Paletas de Colores Sugeridas

Este documento detalla las combinaciones de colores aprobadas para el desarrollo de la interfaz de nuestra aplicación web. Por favor, elija una de las siguientes paletas para mantener la coherencia visual.

## 📝 Instrucciones de Uso
- **Color Primario:** Usado para botones principales, enlaces y branding.
- **Color Secundario:** Usado para elementos de apoyo o estados activos.
- **Fondo / Neutro:** Color base para el cuerpo de la aplicación o tarjetas.
- **Acento / Contraste:** Para resaltar información importante o alertas.
- **Oscuro / Texto:** Para tipografía y bordes definidos.
